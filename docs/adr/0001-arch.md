# 0001 — Architecture

**Status:** accepted · **Date:** 2026-09-18

## Decision

485M-parameter decoder-only transformer, deep-and-narrow, one novel component.

| | |
|---|---|
| Layers | 32 |
| Hidden | 960 |
| Heads | 15 Q / 5 KV (GQA 3:1), head_dim 64 |
| FFN | SwiGLU, inner 2560 |
| Vocab | 49,152 BPE + FIM/ChatML specials |
| Context | 2048, RoPE θ=500k |
| Norm | RMSNorm, QK-norm on both attn branches |
| Attention | Differential GQA (two Q/K projections, shared V) on every layer |
| Pattern | full×4 · [sw,sw,sw,full]×5 · full×8 |
| Extras | 4 register tokens, 2 MTP heads (train-only) |
| Optim | Muon (hidden mats) + AdamW (embed/head/norms) |
| Init | N(0, 0.02); residual projs ×1/√(2L) |

## Why

- Depth over width: MobileLLM ablations at ≤1B parameters.
- Differential attention: the single research bet — see [0002](0002-diff-attn.md).
- Every non-standard component has a one-config-line rollback. See §Rollback.

## Alternatives rejected

- Stock Llama-3-500M: no differentiation.
- MoE 8×top-2: too much moving mass for a first pretraining run; queued for v2.
- Multiple novel components: multiplies debugging surface, blocks fault isolation.

## Rollback

| Component | Rollback | Effect |
|---|---|---|
| Differential attention | `attn_kind: gqa`, freeze λ=0 | falls to standard GQA |
| MTP heads | `n_mtp_heads: 0` | heads discarded |
| Register tokens | `n_registers: 0` | drop from tokenized seqs |
| Muon | `hidden_kind: adamw` | one optimizer for all params |
| Mixed attention | all `full` in `attn_pattern` | +40% attention FLOPs |
| QK-norm | `qk_norm: false` | stability risk late in training |

Full derivations in `paper/void_v1.tex` §3.
